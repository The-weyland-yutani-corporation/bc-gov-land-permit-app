# Approved brand asset integration point

No approved BC Mark artwork is bundled in this repository. The visible
`data-brand-placeholder` element is intentionally text-only and must not be
treated as artwork.

Before an authorized official deployment:

1. Obtain the current web-ready BC Mark from Government Communications and
   Public Engagement (GCPE), or another source explicitly approved by the brand
   owner for this deployment.
2. Record the asset filename, orientation, source URL or handoff record,
   approver, approval date, and usage scope in root `DESIGN.md`.
3. Save the unmodified artwork in this directory. Do not redraw, recolour, crop,
   distort, separate the elements, or remove the keyline.
4. Replace only the placeholder contents in the shared masthead and footer.
   Preserve proportional scaling, required clear space, accessible text, and a
   web height of at least 50 px for the vertical mark or 25 px for the
   horizontal mark.
5. Keep the demonstration/non-official label until the deployment itself is
   formally approved as an official Government of British Columbia service.
